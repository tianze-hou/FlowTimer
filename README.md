## ✨ 功能特性

### 🎯 任务流程管理

- 可视化任务列表：emoji + 名称 + 时长，一目了然
- 拖拽排序，随时调整步骤顺序
- 预设系统：保存常用流程（晨间流程、工作启动...），一键加载
- 支持 JSON 格式导入/导出，方便备份、分享或迁移到其他设备

### ⏱️ 智能计时

- 每个步骤独立倒计时
- 心流模式：超时后自动切换为正计时，不打断你的专注
- 暂停/继续，精确记录暂停时长
- "我忘记停止了"功能：诚实面对分心，记录大概走神了多久

### 🔔 敲钟报时

- 可选间隔：15 / 30 / 60 分钟
- 基于活跃时间计算，暂停时不计时
- 用 Web Audio API 手工调制的颂钵（Singing Bowl）音效，温柔不打扰——骄傲出品✨

### 💭 闪念记录

- 随时捕捉脑子里突然蹦出来的想法，先放这里
- 自动标注时间戳和当前步骤
- 执行结束后统一汇总，不遗漏任何灵感

### 📊 执行日志

- 表格模式 / 列表模式，两种视图可切换
- 记录完整信息：计划时长 vs 实际时长、心流超时、暂停次数、分心记录
- Markdown 格式输出，一键复制后可直接粘贴到 Obsidian、Notion 或任何你的个人管理系统

## 🚀 快速开始

直接打开 `index.html` 即可使用，无需安装任何依赖。

支持导入导出JSON配置文件，用于备份。

## 🎨 设计理念

为什么说它是神经多样性友好的？

- 🧠 **视觉层次清晰**：emoji 作为视觉锚点，降低认知负荷
- 💚 **不惩罚分心**："忘记停止"不是错误，只是如实记录
- 🌊 **保护心流**：超时后鼓励继续专注，而不是打断你
- 💭 **闪念捕捉**：有想法先记下来，不用离开当前任务
